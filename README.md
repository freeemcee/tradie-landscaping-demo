# Westline Landscapes — Tradie Digital Co. demonstration

A premium, responsive, one-page demonstration website for a **fictional** Perth landscaping business.

## Quick preview
Open `index.html` in a browser. Internet access is needed for Google Fonts and externally hosted Unsplash images.

## Deploy to GitHub + Vercel (free tiers)
1. Create a new GitHub repository (e.g. `tradie-landscaping-demo`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root and commit.
3. In Vercel, choose **Add New → Project**, import the GitHub repository and deploy.
4. Framework preset: **Other**. No build command is required. Output directory is the project root (leave blank/default).
5. Vercel will provide a `*.vercel.app` URL on its free tier, subject to its current terms. Check plan eligibility: a commercial client project may require a paid plan. Alternatively use GitHub Pages or another hosting provider whose terms fit the use.

## Before adapting for a real paying client
- Replace fictional name, all sample copy, images and demo disclaimer with verified client information.
- Replace Unsplash remote photos with client-owned or properly licensed photos. Current photos are illustrative only; never claim they show client work.
- Configure a **real form endpoint** (e.g. Formspree, Basin, Netlify Forms, or custom backend) and test delivery. The current demo form intentionally **does not send or store data**.
- Add a privacy policy appropriate to actual data collection and Australian privacy requirements; check business-specific obligations.
- Add verified phone number, email, service area, legal business details and real customer reviews only if approved and accurate.
- Configure a custom domain and hosting paid for by the client. Check platform commercial-use terms.
- Test keyboard navigation, responsive layouts, links, form validation, accessibility and load speed.
- Obtain client approval before publishing and keep a copy of the agreed scope.

## Edit basics
- `index.html`: copy, page sections, form fields, images' alt text.
- `styles.css`: colors, typography, layouts and photo URLs.
- `script.js`: mobile menu and demonstration form behavior.

## Cost
No paid tools are required to create or preview this demo. A domain, commercial hosting and a production form service may cost extra. Do not promise that every deployment is free.
